## 易流云(webgispro) 车辆轨迹地图截图

需求：对 https://webgispro.e6yun.com/map/#/track 查询指定车辆+时间段，截取「纯地图轨迹图」（不含页面 UI、完整轨迹）。

已完成：粤ACJ959 / 2026-09-27 00:00:00~23:59:59，轨迹点 314、19857 个坐标点，输出
`outputs/track_粤ACJ959_20260927.png`（1800x2162，2 倍高清，无 UI，轨迹居中占 75%宽/92%高）。

技术要点（脚本在 `tools/`）：
- 控制端：`playwright-core` + 系统 Chrome（`C:\Program Files\Google\Chrome\Application\chrome.exe`），
  `launchPersistentContext` 带 `--remote-debugging-port=9222`，headful。
- 登录态：从 `%LOCALAPPDATA%\Google\Chrome\User Data` 复制 `Local State` +
  `Default/Network/Cookies` + `Local Storage`/`Session Storage`/`IndexedDB` 到独立 profile。
  复制来的登录态通常已过期 → 仍需用户手动登录一次。
- **关键**：登录后必须让浏览器常驻（start.js 不退出），后续用 `connectOverCDP` 复用；
  若强杀 node 进程，cookie 未落盘会导致登录态丢失（踩过这个坑）。
- 车辆选择：`.tack-search-box .el-select.item-r input` 是 readonly，Playwright `fill` 会超时；
  要点开下拉后用 DOM `.click()` 选中匹配文本的 `.el-select-dropdown__item`。
- 时间：`.el-date-editor.datetime input` 可编辑，默认已是当天 00:00:00~23:59:59；查询按钮 `button.search`。
- 地图实例：`window.maplet`。`setFitView` / `setBounds` 无效，`setZoom` / `setZoomAndCenter` 有效。
  用 `getAllOverlays('polyline')` + `getPath()` 自己算经纬度范围再定位。
- 截图：CDP `Emulation.setDeviceMetricsOverride`（竖版 900x1200，dsf=1）+ `Page.captureScreenshot`
  clip `.amap-container` 且 `scale:2`；截图前隐藏 `.e6-header/.tack-search-box/.tack-action/.track-list/
  .amap-scalecontrol/.amap-logo/.amap-copyright` 等。
- 图像验证（看不到图时）：PIL 统计颜色，轨迹线主色为绿色 (77,168,32)，据此算 bbox/居中度。

备注：agent-browser CLI 的 `open` 在本机启动会长时间挂起，改用 playwright-core 更可控。

## 第二轮：改为 16:9 横版 + 批量 3 台车（踩坑记录）

用户反馈：要 16:9 横版；上一版把地图角落的页面组件也拍进去了。批量任务：
粤ACJ959 09-22 22:48:51~09-26 08:29:18 / 粤BNV030 09-24 03:51:23~09-26 14:08:12 /
粤BPV550 09-25 03:06:29~09-26 10:07:01。最终产物 `outputs/track_粤*_*16-9*.png`（16:9，轨迹填满高度 92%）。

关键坑（都已解决）：
1. **element screenshot 会拍进覆盖物**：`locator('.amap-container').screenshot()` 截的是屏幕区域，
   浮在上面的页面组件（搜索面板、图层图标、比例尺等）都会入镜。必须先把它们隐藏。
   通用规则：`.map-box` 内「子树里没有 canvas / .amap-icon / .amap-marker-label」的元素全部 display:none。
2. **不要隐藏 .e6-header / .track-list**：它们参与布局，隐藏后容器变高，但高德 canvas 尺寸在
   **初始化时**就固定了，结果底部出现 119px 空白。
3. **地图 canvas 尺寸只在页面初始化时确定**：中途用 `Emulation.setDeviceMetricsOverride` 改视口，
   canvas 不会跟着变（dispatch resize 无效）。所以正确顺序是：先定视口 → 再 load 页面 → 再操作。
4. **同 URL（含 hash）的 `page.goto` 不会真正重载**，SPA 里必须再调 `page.reload()`，
   否则上一轮隐藏 UI 的内联样式还在（表现为元素明明在 DOM 里却点不动）。
5. `Emulation.clearDeviceMetricsOverride` 对别的 CDP session 设的覆盖无效，要用 set 覆盖。
6. **高德不支持小数 zoom**（setZoomAndCenter(7.42) 实际落到 7），所以想让画面填满不能靠微调 zoom，
   得反过来按轨迹比例挑画布尺寸：z 取满足 needH(z) <= H*0.92 的最大整数，H = needH(z)/0.92，W = H*16/9。
7. 校验缩放要用 `maplet.getBounds()` 逐点比对（inside/outside），且 setZoomAndCenter 后必须等 ~1.8s 再校验，
   否则读到的是旧视野（曾因此把地图停在 zoom 3，轨迹缩成一点）。

流程（run_batch.js）：标准视口查询拿经纬度范围 → 算专属 16:9 画布尺寸 → 按新尺寸重载再查一次 →
设 zoom → 校验 outside=0 → 隐藏浮层 → CDP captureScreenshot(clip=容器, scale=2)。
