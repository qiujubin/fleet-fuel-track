## 第三轮：改 1 倍输出（用户偏好）

用户反馈"字体还是偏小"，要求不放大两倍。已改为 **DPR 默认 1**（`--dpr=N` 可调）：
输出 1976×1112 / 1922×1081 / 1555×875（约 0.5~0.7MB，原 2 倍是 1.8~2.8MB）。

**用户偏好记录**：易流云轨迹图默认用 1 倍输出（与浏览器观感一致），需要高清细节时才 `--dpr=2`。

技术说明（重要认知）：高德地名字号是固定 CSS 像素，**倍率不改变"文字占画面的比例"**——
1x 和 2x 的图在同样显示尺寸下文字观感相同。所以若用户仍嫌字小，方向不是调倍率，而是：
① 缩小留白 FILL 0.92→0.98（图更紧凑，字占比上升）；
② 分段截图（把长轨迹拆成几段，每段 zoom 更高、地名更详细）；
③ 接受——跨省完整轨迹在 zoom 8 下地名字号本就如此。

踩坑：DPR 常量用 `argv.dpr` 会因 `argv` 定义在后面而报 "Cannot access 'argv' before initialization"，
改为直接解析 `process.argv`。

## 第四轮：缩到 1280×720（最终定稿）

用户选择"缩图"方案 → 已实现为**按目标尺寸渲染画布**（不是渲完再缩位图，那样字占比不变且会糊）。
新增 `--w/--h` 参数，默认 1280×720；视口高 = 画布高 + 119；不再二次裁剪，直接输出整块画布。

实测：三张均 1280×720 / 335~363KB / zoom=7 / outside=0 / markers·icons 保留 / 62 秒跑完。
轨迹 fillH 0.69 / 0.61 / 0.52（比大画布版低，是小画布低 zoom 的必然代价）。

**核心公式（以后别再绕弯路）**：高德地名字号固定 CSS px，
「字占画面比例 = 12 / 画面宽度」。所以让字显大的唯一手段是**减小输出宽度**，
倍率 `--dpr` 和"渲完再缩图"都无效（等比缩放，占比不变）。
代价：画布变小 → fit 完整轨迹只能用更低 zoom → 底图细节层级变少。

用户尺寸偏好：日常看线路走向用 1280×720；要细节时再 `--w=1976 --h=1110 --dpr=2`。
