
# 2026-11-04

## 重大事件：JSA 宏丢失 + 成功修复

跑批时 `daily_run.py` 在验证环节抛 `KeyError: 'xl/JDEData.bin'`。
排查确认：**宏在 11-03 之后、11-04 用户保存之前就丢了**，与本次写入无关。

证据链：
| 时间点 | JDEData | jdecontrol | 大小 |
|---|---|---|---|
| 11-03 备份 | ✅ | 29 | 2.8 MB |
| 11-04 写入前备份 | ❌ | 0 | 12.1 MB |
| 当前（写作前） | ❌ | 0 | 14.3 MB |

文件从 2.8MB → 12.1MB，且 Content_Types 里多出 `richData`/`pivotCacheDefinition10~12` 等
**Excel 专有部件** —— 基本可断定是**用 Excel 打开并保存过**，Excel 会丢弃 WPS 的 JSA 部件。

### 修复方法（tools/restore_jsa.py，已验证成功）
不整表覆盖（会丢用户数据），而是**只注入宏部件**：
1. 从 11-03 备份取 `xl/JDEData.bin` + `xl/jdecontrols/*.xml`（29 个）
2. 五个 `drawing{1,3,5,7,9}.xml`：按 `</xdr:spPr>` 顺序插回 `jdecontrolRef` 块
   （形状数与控件数 1:1 对应，实测 1/7/7/7/7）
3. 对应 `drawing*.xml.rels` 追加 `jdeControlExtension` 关系（**重新分配 rId**，
   因为当前文件 rId 已被 Excel 重排，不能沿用备份的号）
4. `workbook.xml.rels` 追加 `jdeExtension → JDEData.bin`（新 rId50）
5. `[Content_Types].xml` 补 30 条 Override

结果：232 部件、zip 完整、WPS 正常打开、四张可视化表各 **7 个 Shapes（按钮全回来）**、
数据完好。备份：`backup_track_20261104_after/油耗考核10月_宏_当前.xlsm`（修复前状态）。

### 教训
- **绝不能用 Excel 打开这个 .xlsm 再保存**，只能 WPS。
- 本次是 `daily_run.py` 的验证环节救的场——它拦住了"看似成功"的写入。**验证不能省**。
- 已给 daily_run 加了存在性前置检查，宏缺失时给明确指引而不是 KeyError。

## 第二轮：宏恢复后用户反馈"很多东西还是丢了"

全面比对（部件级 → 值级）结果：

**部件级一个没丢**（备份有而当前没有的部件：0 项）。只多了 `xl/richData`（Excel 特性）
和 media/pivotCache 增量（今天的图 + 用户刷新透视表）。

**值级丢了 15 处**（Excel 重写时清掉的零散单元格）：

| sheet | 位置 | 内容 |
|---|---|---|
| 每日油耗数据 | A1 | 系统编号 |
| 每日油耗 | C1 | =TEXT(TODAY()-1,"mm月dd号")&"油耗汇总" |
| 每日油耗 | A5 | 2026-11-02 |
| 每日尿素 | C1 | =TEXT(TODAY()-1,"mm月dd号")&"尿素汇总" |
| 每日尿素 | A5 | 2026-07-10 |
| 每日加油记录 | N4 | 冷机加油：310元 |
| 干线油耗可视化 | O2 / J6 / K6 | 日期 / 粤BPV550 / 1.1748… |
| 华北·华东·华南可视化 | O2 | 日期 |
| 华南可视化 | P2 | =TODAY()-1 |
| 尿素可视化 | O2 / P2 | 日期： / =TODAY()-1 |

补回 15 处（公式用 `.Formula`，日期用序列号 `to_excel`）。

**坑**：
- `Value2` 往被 `Locked=True` 的单元格写字会报"发生意外"，改用 `.Formula = '=DATE(...)'` 可绕过。
- 每日尿素的 A5 最终只能写成 `="2026-07-10"`（公式串），显示正确但不是纯文本。
- **按相同地址比对有假阳性风险**：用户删过空行导致内容整体上移，
  某些地址"备份有、当前无"其实只是错位，补的时候要核对相邻行。

## 教训（补）
`daily_run` 的 verify 只比 jde/ctrlProps，**没比单元格值**。若要防"静默丢内容"，
应加一步「与上次备份做值级抽样对比」。但每天全表比会很慢，可只比表头/关键单元格。
