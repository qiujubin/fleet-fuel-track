# 2026-10-03

## 新增一键跑批 daily_run.py（省 token / 时间）

用户问"为什么又慢又吃 token"，分析后确认主因是 **orchestration 层**：
每天 10+ 次工具调用、全量日志进上下文、重复验证输出。

新建 `tools/daily_run.py`，把全流程合并为**一条命令**：

```
python tools/daily_run.py
```

流程：占用检查 → 备份 → excel_tasks2 → trackshot → fill_wps2 → JSA/写入/图片验证
→ 写当日记忆 → git 提交推送。

**输出设计（异常驱动）**：
- 正常路径只打 4~6 行：`[任务] N 台`、`[截图] n/N 台完成`、`[写入] 车牌 最高/平均 …`、
  `[验证] JSA宏逐字节一致 ✓ 图片 N 张`、`[git] 已提交并推送 ✓`
- 只有 FAILED / 速度未取到 / JSA 不一致 / 行数不符 时才展开细节并退出码 1
- 子命令的 stdout 全部 capture，不倒进上下文

参数：`--no-git` 跳过 git；`--no-shot` 只重写已有结果。

预估效果：每天从我这边 10+ 次调用降到 **1 次**，token 省约 2/3。
下次跑批直接用这个脚本。
