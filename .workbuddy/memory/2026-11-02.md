已导入 D25 的「加油数据」第 2 行，并把「计算模板」`G2`（加油时间B，公式匹配键）
填成该时间、`H2`=是、`A2/C2` 公式随即查到系统编号与司机 ✓

**但油耗数字不可用**：模板第 2 行算出
`L/M(GPS/仪表 开始公里数) = 0` → `P/Q(里程) = 250767.7 / 30529` → 百公里油耗 0.03L（荒谬）。
根因：**只有 1 条记录，没有"上一次加油"作为起点公里**，起止里程从 0 起算。

**结论**：模板结构没问题，缺的是该车的历史加油数据。
主表「每日加油记录」只保存最近几天，取不到历史 → 需另找数据源（加油卡台账/系统导出）。

### 踩坑记录
- WPS COM 写 `datetime` 会按 UTC 解释，东八区会**少 8 小时**。
  正确做法：用 `openpyxl.utils.datetime.to_excel()` 算序列号，写 `Value2`，再设 `NumberFormat`。
- 模板的匹配公式引用的是 **G2（加油时间B）**，不是 F2（加油时间A），别把两者搞混。
