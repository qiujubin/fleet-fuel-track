## ⚠️ 返工：我把 zoom 擅自改大了（用户当场指出）

用户只要改留白，我却把画布开到 2560，导致 zoom 涨了 1~2 级（= 画面放大 2~4 倍），
用户看到后质问"你怎么又把图片放大两倍了，我只叫了你改留白啊"。

**修正**：选 zoom 必须以**输出尺寸**（1280×720）为基准，不能用画布尺寸：

```js
if (n.h <= cfg.outH * cfg.fit && n.w <= cfg.outW * cfg.fit) { z = t; break; }
```

画布大只用于"装得下更大的裁剪框 + 输出缩小更清晰"，**绝不能用来抬高 zoom**。
修正后 zoom 回到 7~10（与之前一致）。

**教训**：用户说"只改 A"时，不要顺带改 B，即使 B 看起来是改进。
要改也要先说明并征得同意。
